# SW_Spur_Gear.bas

SOLIDWORKS 用の VBA マクロです。歯数・モジュール・歯幅を入力すると、インボリュート平歯車の形状を自動で作成します。

## 機能

- 歯数・モジュール・歯幅を `InputBox` で入力
- 歯先円の円盤を押し出し
- インボリュート曲線をもとに歯溝をカット
- 中心軸を作成し、その軸で円周パターン

## 動作確認環境

- SOLIDWORKS 2026（作成者の環境で、歯車の作成完了まで確認）
- 他のバージョンでは未確認です。引数や API の仕様がバージョンによって異なる場合があります。

## 使い方

1. SOLIDWORKS で VBA エディタを開きます（ツール → マクロ → 編集、など）。
2. `SW_Spur_Gear.bas` の内容をコピーして、標準モジュールとして貼り付けるか、ファイルとしてインポートします。
3. `main` を実行します。
4. 入力ダイアログで以下を順に入力します。
   - 歯数（6〜200、初期値 20）
   - モジュール（mm、初期値 2）
   - 歯幅（mm、初期値 15）
5. 完了メッセージが出れば作成完了です。

キャンセルすると、その時点で処理を終了します。

## 前提条件

- 新規部品を作成してから処理を行います（既定テンプレート、または `NewPart` で作成）。
- 基準平面の名前は次のいずれかを想定しています。
  - 正面 / Front Plane
  - 右側面 / Right Plane
  - 平面 / Top Plane（上面）
- 歯車の回転軸は、正面と右側面の交線（Z 軸相当）です。

日本語版と英語版の平面名の違いに対応していますが、別名で設定されている環境では、コード内の名前の配列を書き換えてください。

## 既知の制限

- **歯底の形状**: 基礎円より内側は径方向の直線で近似しています。実際の歯底（トロコイド）とは形が異なります。
- **円周パターン**: `FeatureCircularPattern5` は API ヘルプで Obsolete（非推奨）と記載されています。将来のバージョンで使えなくなる可能性があり、`CreateFeature` への移行を検討する必要があります。
- **カット方向**: 押し出しカットの方向は、`Dir` を切り替えて成功する方を使う仕組みです。
- **歯数の下限**: 歯数が少ないと、基礎円と歯底円の関係から形状が崩れることがあります。
- **引数**: `FeatureExtrusion3`、`FeatureCut4`、`FeatureCircularPattern5` などの引数は、使用するバージョンの API ヘルプで確認してください。
